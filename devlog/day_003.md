## Deriving a suitable PDF / inverse PDF for x^2 over [0, 2].

To use a function as a PDF:
- it must integrate to one, over the domain.
- you must be able to analytically invert its CDF to generate random samples.

So, since x^2 is very close to zero close to x = 0, and largest at x = 2, we
want to choose a function that mimics that behaviour.

The function p(x) = x / 2 has the "same" properties. It assigns a low
probability near zero, and a high probability near 2. This means that we waste
fewer samples on regions where f(x) is close to zero.

The CDF of $p(x) = x / 2$ is $x^2 / 4$. We invert it quite easily:

$u = x^2 / 4 \rightarrow \sqrt(4u) = x => x = 2\sqrt(u).$

## Rejection sampling

Note that [rejection
sampling](https://en.wikipedia.org/wiki/Rejection_sampling) is an alternative
to inverse sampling transform. They are both ways of drawing samples from a
distribution p(x). Rejection sampling does this by first drawing samples from a
simpler proposal density g(x).
