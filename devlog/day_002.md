## Sampling the bilinear function

In `src/sampling/linear.rs` we generate samples according to some distribution
(linear interpolation) by transforming the canonical random variable X in a
particular manner. In this case, we transform it from $[0, 1)$ to $[0, total)$.

In order to generate samples from the bilinear distribution, we first create a
marginal distribution over one dimension, and then we sample that.

Inversion is equally simple, as we've just composed two linear samples, so we
can invert that using two linear sample inversions.
